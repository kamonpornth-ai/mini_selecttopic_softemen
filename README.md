#  Digital Pocket Store 

> A modern, minimalist digital product marketplace designed 
> แพลตฟอร์มร้านค้าขายสินค้าดิจิทัล (E-Book, Templates, UI Kits)

## 🎨 UI/UX Design Concept: "Minimalist & Trustworthy"

การออกแบบมุ่งเน้นไปที่ความเรียบง่าย สะอาดตา (Minimalist) เพื่อให้ตัว "สินค้า" โดดเด่นที่สุด ผสานกับการใช้โทนสีที่ให้ความรู้สึกปลอดภัยและน่าเชื่อถือ เนื่องจากเป็นแอปพลิเคชันที่มีการทำธุรกรรมทางการเงิน

### 🌈 Color Palette (Design System)
เราใช้โทนสีที่ทันสมัยและสบายตา เพื่อให้ผู้ใช้สามารถใช้งานแอปได้นานโดยไม่ล้าสายตา:

*   **🔵 Primary Color (Navy Blue - `#0F172A`):** ใช้เป็นสีหลักบริเวณ Bottom Navigation และ Header ให้ความรู้สึกพรีเมียม น่าเชื่อถือ และปลอดภัย
*   **⚪ Background Color (Off-White - `#F8FAFC`):** สีพื้นหลังที่สว่างแต่ไม่ขาวจ้าจนเกินไป ช่วยให้การ์ดสินค้า (Product Cards) ดูมีมิติและโดดเด่นขึ้น
*   **⚡ Accent Color (Electric Blue - `#3B82F6`):** สีรองที่ใช้สำหรับดึงดูดสายตา (Call to Action) เช่น ปุ่ม "Add to Cart" หรือ "Download"
*   **🌑 Text Color (Slate Gray - `#334155`):** สีข้อความหลักที่ลดความเข้มลงจากสีดำสนิท เพื่อความสบายตาในการอ่าน (Readability)

## ✨ Core Features & Navigation Flow

แอปพลิเคชันถูกออกแบบ UI โดยยึดหลัก **Thumb-Friendly Navigation** (ใช้งานง่ายด้วยนิ้วโป้งมือเดียว) ผ่าน Custom Bottom Navigation Bar:

### 🏠 1. Home (หน้าหลัก & ค้นหาสินค้า)
*   **Smart Search:** แถบค้นหาด้านบนสุด สำหรับผู้ใช้ที่ทราบความต้องการอยู่แล้ว
*   **Hero Banner:** พื้นที่โปรโมตสินค้าใหม่หรือแคมเปญลดราคา (Horizontal Scroll)
*   **Category Pills:** เมนูหมวดหมู่แบบวงกลม เข้าถึงหมวดหมู่ย่อยได้รวดเร็ว
*   **Product Grid:** การแสดงผลสินค้าแบบ Grid ที่สะอาดตา พร้อมราคาและปุ่มเพิ่มลงตะกร้า

### ❤️ 2. Wishlist (รายการโปรด)
*   บันทึกสินค้าดิจิทัลที่สนใจไว้เพื่อตัดสินใจซื้อในภายหลัง (Save for later) ช่วยเพิ่มโอกาสในการเกิด Conversion Rate

### 🛍️ 3. Quick Action (Center Floating Button)
*   ปุ่มตรงกลางที่โดดเด่นที่สุดบน Bottom Nav ถูกออกแบบมาเพื่อเป็น **ตะกร้าสินค้า (Cart)** หรือ **Scan/Action หลัก** เพื่อให้ผู้ใช้เข้าถึงขั้นตอนการชำระเงิน (Checkout) ได้เร็วที่สุดโดยไม่มีสะดุด

### 📥 4. My Library (คลังสินค้าของฉัน)
*   หน้าต่างสำหรับการจัดการคำสั่งซื้อ (Order Management)
*   แบ่ง Tabs ชัดเจนระหว่าง **"ประวัติการสั่งซื้อ (Order History)"** และ **"ไฟล์ที่พร้อมดาวน์โหลด (Ready to Download)"** 

### 👤 5. Profile & Settings
*   หน้าการตั้งค่าบัญชีผู้ใช้ (Account Management), การรักษาความปลอดภัย, และการปรับแต่งแอปพลิเคชัน (เช่น Dark/Light Mode)
